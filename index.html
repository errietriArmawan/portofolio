Prediksi diabetes dengan machine learning (tugas akhir, terbit di jurnal)

Membandingkan tiga model (Logistic Regression, Random Forest, dan XGBoost) untuk memprediksi diabetes dari data klinis Pima Indians (768 pasien). Fokusnya pada evaluasi yang ketat agar hasilnya tidak terlalu optimistis: nested cross-validation dan pipeline pra-pemrosesan yang mencegah kebocoran data.

Ketiga model setara secara statistik (uji Friedman, p = 0,819), jadi Logistic Regression dipilih karena paling stabil dan paling mudah dijelaskan. Pada data uji: AUC-ROC 81,4% dan akurasi 69,5%. Menurunkan threshold ke 0,30 menaikkan recall menjadi 83,3%, cocok untuk skrining. Analisis SHAP menunjukkan glukosa dan BMI sebagai faktor paling berpengaruh, sesuai pedoman ADA dan WHO.

Python · scikit-learn · XGBoost · SHAP · Nested cross-validation
